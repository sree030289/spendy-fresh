This document provides context about the MeetNSplit project to help Claude understand the codebase and answer questions effectively.

Project Overview
MeetNSplit (also known as Spendy) is a React Native mobile application for expense splitting and financial management. It allows users to split bills, track expenses with friends and groups, scan receipts, and manage settlements.

Tech Stack
Frontend: React Native with Expo SDK 53
Backend: Firebase Cloud Functions (Serverless)
Database: Firebase Firestore
Authentication: Custom JWT implementation via ApiService
Navigation: React Navigation 7 (bottom tabs + stack navigation)
State Management: React Context API (AuthProvider, ThemeProvider)
Notifications: Expo Notifications + Custom notification system
Payments: RevenueCat for subscriptions
Package Manager: Yarn
