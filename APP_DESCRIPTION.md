# Spendy - AI App Description

**Spendy** is a React Native expense-sharing app for groups (roommates, trips, friends) built with Firebase backend.

## Core Features:
1. **Expense Splitting**: Users scan receipts/add expenses, automatically split costs among group members
2. **Smart Groups**: Organize expenses by context (roommates, trips, events) with real-time balance tracking
3. **AI-Powered**: Receipt OCR scanning, spending insights, and personalized financial analytics
4. **Deals Integration**: Exclusive cashback offers and discounts from partner brands
5. **Settlement System**: Smart algorithms to minimize transactions when settling group debts

## Technical Stack:
- **Frontend**: React Native (Expo) with TypeScript, custom UI components, animations
- **Backend**: Firebase (Auth, Firestore, Functions, Storage)
- **Key Services**: Receipt scanning (AI/OCR), push notifications, QR code payments
- **Navigation**: Tab-based with Auth/Main screens, onboarding tour system

## App Flow: 
Login → Onboarding Tour → Main Dashboard (Expenses/Groups/Profile) → Add/Split Expenses → View Balances → Settle Debts → Discover Deals

The app solves the pain point of tracking shared expenses and eliminates the awkwardness of asking friends for money.
